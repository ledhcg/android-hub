# Documentation and text

- English only. Plain, direct sentences. Document decisions and constraints (why), not tutorials the code already shows.
- Keep `README.md` (users), `CONTRIBUTING.md` (contributors), `docs/ARCHITECTURE.md` (design decisions), `docs/design/` (UI),
  `ROADMAP.md` (open work), `CHANGELOG.md` (what changed) in their own lanes; link instead of duplicating.
- Never include personal data (names, emails, serials, content of other apps or devices) or session/tool links in committed files.
- Do not credit or compare against third-party apps as a design source.
- Update docs in the same change as the behaviour they describe.
